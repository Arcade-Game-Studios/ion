# Ion Engine Documentation

Project documentation for the Ion Engine, a cross-platform C++ game framework.

## Layout

- `../README.md` — project overview and build instructions
- `../todo.md` — development roadmap organized by phases
- `../include/ion/` — public API headers (the contract for engine users)
- `../core/` — core engine implementation (application, lifecycle)
- `../platform/` — platform backends (window system per OS)
- `../render/` — rendering subsystem and graphics backends
- `../editor/` — editor application
- `../examples/` — example programs using the public API
- `../tests/` — tests and test applications

## Documentation Status

Phase 0 (foundation) documentation is a work in progress. Detailed API
reference and architecture documents will be added as modules are implemented.
